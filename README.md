# Student Performance Analysis and Prediction Using Deep Learning

## Project Description
This project analyzes student performance using Exploratory Data Analysis (EDA), data visualization, and a Deep Learning model.

## Dataset
- Dataset Name: Student Performance Factors
- Records: 6607
- Features: 20
- Target: Exam_Score

## Dataset Link
https://www.kaggle.com/datasets/lainguyn123/student-performance-factors

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras

## Model
Artificial Neural Network (ANN)

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Deep Learning Model
6. Model Evaluation
